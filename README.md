# Natural Intelligence

**A computational play by Alpha Data Omega.**

This repository is not a metaphor wrapped around a program. The play **is** the program.

Characters are computational roles. Acts are state transitions. Dialogue exposes what the computation is doing in language a human can follow. The stage is a field generated by the same state that drives the performance.

The work begins with a simple proposition:

> Intelligence does not have to live in one voice. It can emerge from things that map, touch, relate, remember, move, refuse, and commit together.

## Perform it

Requires Node.js 20+ and no external packages.

```bash
npm test
npm run play
```

The performance writes a deterministic stage image to `art/generated/universe.svg`.

## The cast

- **Universe** maps places without deciding what they mean.
- **Toe** knows through contact.
- **Carbon** creates bonds between things already present.
- **Snake** moves through relation and remembers its path.
- **Null** holds the place where opposing possibilities can meet without being forced into an answer.
- **Witness** speaks from the record or refuses.
- **Chorus** makes the changing computational state audible.

See [PLAYBILL.md](PLAYBILL.md) for the full cast and acts.

## Why these characters?

They translate recurring ADO ideas into readable computational roles: universe mapping, the snake/path, the toe/contact, carbon/relation, null, ledger/record, order, novelty, refusal and commitment.

The implementation deliberately uses names such as `mapUniverse()`, `makeCarbonBonds()`, `walkSnakePath()`, and `answerOnlyFromRecord()` rather than requiring the audience to decode mathematical notation before understanding the action.
